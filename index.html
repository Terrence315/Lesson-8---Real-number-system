The Real Number System

Mathematics 700 Fundamentals • Unit 1: Integers • Assignment 20

Quick Review

Natural
1, 2, 3, ...
Whole
0, 1, 2, 3, ...
Integers
..., -2, -1, 0, 1, 2, ...
Rational
Fractions; terminating or repeating decimals
Irrational
Decimals that do not terminate or repeat
Real
Rational + irrational
Subset map:
Natural ⊂ Whole ⊂ Integers ⊂ Rational ⊂ Real
Irrational ⊂ Real, and irrational is separate from rational.
